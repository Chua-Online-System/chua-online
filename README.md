## 🏛️ Quần Thể Danh Lam & Tính Năng Hoàn Chỉnh

### 1. ⛩️ Cổng Tam Quan & Chánh Điện Tam Bảo
- **Dâng Tâm Hương:** Thắp 1, 3 hoặc 5 nén nhang trầm với tàn nhang và khói bay chân thực (Canvas 2D Particle).
- **Thỉnh Đại Hồng Chung:** Tiếng chuông đồng ngân vang, mô phỏng sóng âm lan tỏa xua tan phiền não.
- **Thùng Công Đức:** Cúng dường gieo duyên tùy tâm, hiệu ứng đồng xu rơi sinh động, ghi danh tấm lòng vàng.
- **Xin Xăm & Xin Keo:** Gieo quẻ xăm đầu năm, luận giải thẻ bài tâm linh và gieo quẻ âm dương.
- **Ghi Sổ Vàng Cầu An:** Lưu lời nguyện cầu an cho gia tiên, bá tánh (có bộ lọc từ ngữ trang nghiêm).

### 2. 📿 Không Gian Tu Tập & Tịnh Tâm (Nhà Tụng Kinh & Thiền)
- **Tràng Hạt 108 Biến:** Chuỗi hạt niệm Phật tương tác, mô phỏng tiếng gõ mõ gỗ trầm ấm (Web Audio), haptic rung phản hồi trên điện thoại, tự động đếm số chuỗi hoàn thành.
- **Toạ Thiền Định Zen:** Chuông xoay Tây Tạng 432Hz, hẹn giờ thiền (3 - 30 phút), vòng tròn thở điều hòa thân tâm (4s hít - 4s giữ - 4s thở - 2s tịnh), chế độ Zen toàn màn hình.
- **Thư Viện Kinh Điển:** Chú Đại Bi 84 câu, Bát Nhã Ba La Mật Đa Tâm Kinh toàn văn, chế độ đọc chữ lớn, tự động cuộn chữ và nhịp gõ mõ đều đặn.
- **Lời Phật Dạy (Pháp Thoại Mỗi Ngày):** 25 câu pháp thoại tinh hoa, xuất ảnh thiệp thư pháp giấy dó cổ phong kèm triện đỏ lưu về máy chia sẻ phước lành.
- **Nhật Ký Tu Tập & Hồi Hướng:** Theo dõi chuỗi ngày tịnh tâm liên tục (streak), lịch hoa sen 30 ngày, thống kê tổng biến niệm kinh, phút thiền và ghi chép lời hồi hướng công đức.

### 3. 🌿 Không Gian Sinh Thái & Tương Tác Cảnh Quan
- **Hồ Cá Koi Phóng Sinh (Canvas 2D):** Đàn cá bơi lội mềm mại theo thuật toán bầy đàn Boids (Kohaku, Taisho Sanke, Yamabuki), thả cá ảo gửi gắm lời nguyện thiện lành, rắc mồi nuôi dưỡng và cá lớn dần theo thời gian thực.
- **Vườn Bồ Đề Tâm:** Gieo mầm cây Bồ Đề của riêng bạn, trải qua 5 giai đoạn sinh trưởng (Hạt mầm → Chồi non → Cây con → Trưởng thành → Cổ thụ). Tưới nước mỗi ngày và treo dải lụa nguyện ước đung đưa trên cành biếc.
- **Bến Thả Hoa Đăng Sông Đêm (Realtime):** Dòng sông đêm trăng tĩnh mịch với hàng ngàn hoa đăng sen hồng trôi về chân trời xa. Tích hợp **Supabase Realtime Broadcast** cho phép các Phật tử nhìn thấy hoa đăng của nhau trôi đồng thời, tự động bật thông báo Lễ Hội Đêm Rằm (14-15 âm lịch) và Mùng Một.
- **Vườn Sen Phước Lành:** Chiêm bái vườn sen bách hoa nở rộ (Bạch Liên, Hồng Liên, Kim Liên), trao tặng hoa sen chúc lành và xuất thiệp sen thư pháp gửi người thân.
- **Bản Đồ Quần Thể Chùa 2.5D:** Tranh thủy mặc mô tả bao quát 9 phân khu chùa với thanh điều khiển chân trang tiện lợi, không bị che khuất góc nhìn.

### 4. 🏔️ Hành Hương Núi Cao 3D (WebGL / Three.js)
- Trải nghiệm leo núi lên đỉnh thiền môn, qua cổng tam quan, cởi dép và dạo bước vào đại điện.
- Hỗ trợ multiplayer online (hiển thị phật tử cùng đi viếng chùa, bong bóng trò chuyện).
- Thanh công cụ HUD tiện lợi: Chuyển đổi 1 chạm giữa Chánh Điện 2D, Bản Đồ 2.5D, Sinh Thái và Tu Tập.

### 5. 📱 Tối Ưu Hóa Trải Nghiệm & Tiện Ích Cao Cấp
- **Mobile Zen Bottom Bar:** Thanh điều hướng cố định mép dưới điện thoại tiện dụng như app native.
- **Zen Night Mode:** Chuyển toàn bộ màu sắc sang nền gỗ sẫm cổ kính (`#140f0a`), ánh đèn lồng vàng ấm dịu mắt.
- **Bảng Âm Thanh Thiền Procedural:** Tùy chỉnh âm lượng và chọn 4 không gian âm thanh (*Ngũ Cung Thiền, Mưa Mái Chùa, Suối Rừng Trúc, Chuông Mõ Thanh Tịnh*) tổng hợp 100% bằng Web Audio không phụ thuộc file mp3 ngoài.
- **PWA (Progressive Web App):** Hỗ trợ cài đặt trực tiếp về màn hình chính Android, iOS, Windows, macOS; hoạt động Offline-First.

## 🛠️ Công Nghệ & Kiến Trúc

| Thành Phần | Công Nghệ Sử Dụng |
|------------|-------------------|
| **Framework** | Nuxt 4 (SSR + SPA Route Rules) |
| **Frontend UI** | Vue 3 Composition API, Tailwind CSS |
| **Đồ Họa 3D** | Three.js, TresJS, WebGL |
| **Đồ Họa 2D / Canvas** | Canvas 2D HTML5 (Boids Flocking, Sông hoa đăng, Thư pháp ảnh) |
| **Âm Thanh** | Procedural Web Audio API (chuông xoay 432Hz, mõ gỗ, nhạc ngũ cung, pink noise) |
| **Cơ Sở Dữ Liệu** | Supabase PostgreSQL + Row Level Security (RLS) + Realtime Broadcast |
| **Lưu Trữ** | Local-First Architecture (hoạt động offline 100%, tự động sync khi đăng nhập) |
| **Kiểm Duyệt** | Thuật toán Regex & Badwords Dictionary chống spam và lọc từ ngữ độc hại |

## 🚀 Hướng Dẫn Cài Đặt & Chạy Môi Trường Phát Triển

### Yêu Cầu Hệ Thống:
- Node.js >= 18.x (khuyến nghị Node 20.x hoặc 22.x LTS)
- npm >= 9.x hoặc pnpm / yarn

```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Khởi chạy máy chủ phát triển
npm run dev
```
Truy cập trình duyệt tại: `http://localhost:3000`

## ☁️ Cấu Hình Supabase (Tùy Chọn — Không Bắt Buộc)

> **Lưu ý:** Nếu không cấu hình Supabase, hệ thống vẫn hoạt động đầy đủ 100% ở chế độ **Local-First** (lưu dữ liệu an toàn trên trình duyệt của người dùng).

Nếu muốn kích hoạt tính năng tài khoản đám mây và đồng bộ hoa đăng Realtime:
1. Tạo project miễn phí tại [supabase.com](https://supabase.com).
2. Vào mục **SQL Editor** trên Dashboard của Supabase, thực thi lần lượt 2 file SQL:
   - `supabase/schema.sql` (bảng cơ sở: prayers, merits, pilgrim_profiles)
   - `supabase/migrations/02_advanced_features.sql` (bảng mở rộng: user_practice_stats, bodhi_trees, pond_fish, river_lanterns)
3. Tạo file `.env` từ `.env.example` và điền khóa API:
   ```env
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_ANON_KEY=your-anon-key
   ```
4. Khởi động lại ứng dụng: `npm run dev`

## 🌐 Hướng Dẫn Deploy Lên Production

Dự án sử dụng Nitro Engine với khả năng tương thích cao trên mọi nền tảng điện toán đám mây:

### 1. Triển Khai Lên Vercel (Khuyến nghị — Nhanh Nhất)
- Kết nối GitHub Repository vào Vercel.
- Vercel tự động nhận diện **Nuxt** framework.
- Thêm Environment Variables trong mục Settings:
  - `SUPABASE_URL`: URL Supabase của bạn
  - `SUPABASE_ANON_KEY`: Anon Key của bạn
- Nhấn **Deploy**.

### 2. Triển Khai Lên Netlify
- Đẩy source code lên Git.
- Tạo site mới trên Netlify, chọn repo `Chua_Onl`.
- Build command: `npm run build`
- Publish directory: `.output/public`
- Cấu hình Environment Variables và nhấn **Deploy**.

### 3. Triển Khai Lên VPS Linux / Docker / Railway / Render (Node.js Server)
```bash
# 1. Build bản production
npm run build

# 2. Khởi chạy Nitro Server độc lập (không cần dev server)
node .output/server/index.mjs
```
*(Mặc định máy chủ sẽ lắng nghe tại cổng `3000`, có thể cấu hình cổng thông qua biến `PORT=8080`).*

Để chạy nền vĩnh viễn trên VPS, bạn có thể dùng **PM2**:
```bash
pm2 start .output/server/index.mjs --name "chua-online"
```
